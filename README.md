# Велес Сталь — лендинг

Статический адаптивный лендинг для ООО «Велес Сталь» с отдельной страницей подбора параметров металлопроката.

## Как открыть

Откройте `site/dist/index.html` в браузере или запустите локальный сервер из папки `site/dist`.

```bash
python -m http.server 4173
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:4173/`.

## Страницы и поведение

- `index.html` — лендинг с адаптивной сеткой для телефона, планшета и компьютера.
- `calculator.html` — форма параметров изделия, живое резюме заказа и расчёт итоговой суммы, когда для выбранного товара подключена подтверждённая цена.

Прайс-листа в исходных данных проекта нет. Поэтому калькулятор уже умеет нормализовать количество, площадь и размеры, но показывает «Цена уточняется», пока в `window.VELES_PRICE_TABLE` не появится согласованная таблица цен. Формат записи: `{ "Металлопрокат:Лист ПВ": { "unit": "т", "amount": 123 } }`. Форма заявки демонстрационная: она проверяет поля, но не отправляет данные на сервер.
