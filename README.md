# Велес Сталь — лендинг

Статический адаптивный лендинг для ООО «Велес Сталь» с отдельной страницей подбора параметров металлопроката.

## Как открыть

Откройте `site/dist/index.html` в браузере или запустите локальный сервер из папки `site/dist`.

```bash
python -m http.server 4173
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:4173/`.

## Страницы и поведение

- `index.html` — лендинг с адаптивной сеткой для телефона, планшета и компьютера.
- `calculator.html` — форма параметров изделия и живое резюме заказа. Кнопка переносит заполненные параметры в поле «Заказ» на лендинге.

Масса и стоимость на странице подбора не вычисляются. Форма заявки демонстрационная: она проверяет поля, но не отправляет данные на сервер. Для реального приёма заявок потребуется подключить согласованный канал отправки и заменить тестовые контакты.
