# API заявок

Основано на предоставленных `main.py`, `config.py`, `requirements.txt`, `.env.example`: сохранены FastAPI, gspread, порядок колонок, московское время и ответ `{ok:true}`. Пакет запускается из корня репозитория: `uvicorn api.main:app`.

Изменены валидация, закрытый по умолчанию CORS, запись RAW вместо USER_ENTERED, таймаут Google, безопасная ошибка 502, проверка заголовков существующего листа и путь к статике `site/dist`. Конфигурация и ключи читаются только сервером. Код не загружает их в браузер.

Для тестов используйте `python -m pytest api/tests -q`. Фикстуры подменяют worksheet, не обращаются к Google. `api.tests.mock_server` обслуживает сайт с записью в память исключительно для локального QA. Инструкция настройки окружения, тестового листа и Beget: [BEGET.md](../BEGET.md).

Тарифы калькулятора не относятся к API заявок. `site/dist/price-policy.js` содержит пустой список тарифов; стоимость без подтверждённого соответствия товара, марки, ГОСТа и единицы не выводится. Тестовые числа в unit-тестах вымышлены и не входят в прайс.
